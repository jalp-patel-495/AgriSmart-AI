# AgriSmart AI – Dataset Guide & Preprocessing Standards

## 🌿 Overview
The AgriSmart AI dataset pipeline processes plant leaf imagery across multiple crop varieties and disease conditions. Clean, consistent data preprocessing is essential to train robust deep learning classifiers.

## ⚙️ Preprocessing & Augmentation Pipeline

### 1. OpenCV Image Ingestion
- Image integrity check: verifies the image file can be decoded cleanly without corrupted headers.
- Color space conversion: standardizes BGR input into RGB format.
- Resizing: target dimensions are standard $224 \times 224$ pixels using `cv2.INTER_AREA` (for downsampling) or `cv2.INTER_CUBIC` (for upsampling) to preserve lesion boundaries.

### 2. Pandas Metadata Manifesting
- Scans class folders and constructs metadata DataFrames containing:
  - `filepath`: Absolute or relative path to processed image
  - `crop`: Name of crop (e.g. Tomato, Corn, Apple, Potato)
  - `condition`: Health status or disease name
  - `class_name`: Full standardized identifier (e.g. `Tomato___Early_blight`)
  - `class_id`: Numeric index from `0` to `N-1`
  - `split`: Dataset partition (`train`, `val`, `test`)

### 3. Albumentations Transformation Pipeline
Field photography involves varying sun glare, shadows, hand tremor, and phone angles. Albumentations applies realistic agricultural augmentations:

- **Training Pipeline**:
  - `HorizontalFlip(p=0.5)`
  - `VerticalFlip(p=0.3)`
  - `RandomRotate90(p=0.5)`
  - `ShiftScaleRotate(shift_limit=0.0625, scale_limit=0.1, rotate_limit=30, p=0.5)`
  - `ColorJitter(brightness=0.2, contrast=0.2, saturation=0.2, hue=0.1, p=0.5)`
  - `GaussNoise(var_limit=(10.0, 50.0), p=0.3)`
  - `Normalize(mean=(0.485, 0.456, 0.406), std=(0.229, 0.224, 0.225))`
- **Validation / Test Pipeline**:
  - `Resize(224, 224)`
  - `Normalize(mean=(0.485, 0.456, 0.406), std=(0.229, 0.224, 0.225))`

## 🎯 Verification
Run `python dataset/scripts/verify_dataset.py` to confirm that:
- All CSV manifests load cleanly into PyTorch `Dataset`.
- `DataLoader` produces batches of shape `(batch_size, 3, 224, 224)`.
- No `NaN` or `Inf` values exist in normalized tensors.
